# U-Tech / U-Tech Plus

U-Tech本体はメイン・環境スコア・データ出力・利用案内・システム情報を表示します。
`u-tech-plus/` は排液量・アラート・分析・WBGT・過去データ・メンテの6タブです。
本体のPlus移動ボタンはパスワード不要です。Next / G-Flow / Yui-Techの既存の移動方法は変更していません。

## ファイル構成

- `index.html`: 本体の画面。
- `assets/utech.css`: 本体・Plus共通のヘッダー、レイアウト、入力・グラフ部品のCSS。
- `assets/utech-main.css`: 本体専用のカード、環境スコア、CSV、表示設定のCSS。
- `assets/utech-shared.js`: グラフ描画・日時・API取得など両画面で使う処理。
- `assets/utech-header.js`: 本体だけで使う現在日時・日の出日の入り表示、農作業こよみ、潮汐・天気取得。Plusでは読み込みません。
- `assets/utech-main.js`: メイン・環境スコア・CSV・表示設定・本体の初期化。
- `u-tech-plus/index.html`: Plusの6タブと共通ヘッダー。
- `u-tech-plus/assets/plus.js`: 6タブの処理とタブ別設定・初期化。
- `u-tech-plus/assets/plus.css`: Plusの6タブ専用CSSと、ロゴ・入力欄・スマホ幅の補正。

両画面とも共通JSを先に、専用JSを次に読み込みます。共通の関数・定数は従来と同じグローバル名で参照されます。本体はPlus専用の取得・計算・設定操作コードを読み込みません。
本体の読み込み順は `utech-shared.js` → `utech-header.js` → `utech-main.js` です。PlusのDIF計算にも使う地域設定・日本時間変換・日の出日の入り計算は共通JSに残し、ヘッダーの表示や外部取得だけを本体専用に分離しています。
単一系列の標準的な線グラフは共通の `createSingleLineChart` で組み立てます。本体の温度・湿度、Plusの黒球温度・WBGT、汎用の単一系列グラフが利用し、データ抽出・軸・表示期間・ズーム・警戒帯プラグインの指定は各作成関数に残しています。複数系列のグラフには適用していません。
CSSも共通を先に、各サイト専用を次に読み込みます。各専用ファイルでは通常時・メディアクエリ内の指定を元の順番で維持し、Plus固有の補正は最後に置きます。
元の処理を移植しているため、グラフや計算の仕様は維持しています。
メンテの電圧だけは直近30日間、それ以外のメンテグラフは既存の期間設定です。

## APIとURL

Plusは `<base href="../">` を使い、既存のPHP APIをルートから参照します。
PHP、DB、アラートのサーバー側通知処理は変更していません。
Plusを閉じたことによってサーバー側の保存済み通知設定が解除されることはありません。
Yui-Tech / Nextのファイルも変更していません。
Plusのヘッダーはロゴ・タイトル・説明・本体への移動・現在日時のみです。地域選択、日の出日の入り、農作業こよみ、今日と明日の予報は表示せず、潮汐・天気の取得も実行しません。
過去データのDIF計算に必要な地域は、本体で保存済みの地域を内部で引き継ぎます（未設定時は既存どおり那覇）。

## user_id / 設定

- 本体からの移動時は、表示へ適用済みのuser_idを `?user_id=` で渡します。
- Plusの初回タブはメンテ。以降は最後に開いたタブを復元します。
- URLのIDは開いたタブへ適用。他タブは各自の保存値を優先し、未設定なら引継ぎIDを使います。
- 直接開いた場合も各タブの保存値を優先。初回移行では既存の分析/WBGT設定や本体のIDを初期値に使います。
- 引継ぎURLは初期化後に取り除き、再読み込みで後の変更を上書きしないようにします。
- 各タブのuser_id・入力条件は `utechPlus_v1_{tab}`、前回タブは `utechPlus_v1_lastTab` に保存します。
- 本体の `usui_user_id` と表示・非表示設定はPlusから上書きしません。
- ID履歴は従来の `usui_user_id_history` を共用します。分析比較元やWBGTの既存キーは互換性のため維持しています。
- 通知先のWebhookやパスワードはPlusの汎用フォーム保存から除外します。アラートの保存先は従来どおりサーバーです。

## 検証

`scripts/test-utech-plus.cjs` はローカルHTTPサーバーと模擬APIを使います。
PlaywrightとMicrosoft Edgeが必要です（`NODE_PATH` でPlaywrightのあるnode_modulesを指定できます）。

```powershell
node scripts/test-utech-plus.cjs
```

検証範囲: 本体グラフ・表示設定、相互移動、初期/前回タブ、タブごとのID分離と保存、分析・WBGT/P51・過去データ、メンテの30日電圧、空データ、390px表示、JavaScriptエラー。
通知やDBの変更はすべてローカルの模擬APIで扱います。実サーバーのデータや通知先は操作しません。
本番API・実センサーでの確認とデプロイは別途必要です。

`node scripts/test-utech-css.cjs` は作業ツリーとHEADのCSSを比較し、本体・Plus全タブをPC幅・スマホ幅・横向きで検証します。画面内スクリプトやAPIは実行せず、静的HTML要素の計算済みスタイルを比較します。動的な描画・操作は上記のブラウザテストで別途確認します。

`node scripts/test-utech-chart-configs.cjs` は作業ツリーとHEADのグラフ作成関数を比較し、データ・軸・プラグイン・コールバック・グラデーション・スマホの期間指定・空データ・キャンバス欠落時の挙動が一致することを検証します。

## 排液量

先頭の排液量タブは共通user_idと3地点（初期値P41・P42・P43）を入力します。各地点の1転倒水量[mL]は実測値を設定し、区間転倒数から1時間・日積算の排液量[L]を表示します。設定はutechPlus_v1_drainageに保存します。初回の表示タブは従来どおりメンテです。

get_drainage_data.phpはP41雨量APIの集計処理を再利用します。係数およびAPI応答の数値単位はmLで、画面では1000で除してLに換算します。欠測はnull、日積算は日本時間0時でリセットし、既知の値のみ合計します。表示・更新ボタンとタブ再表示で再取得します。

送信機は既存雨量計と同様にinsert.phpへrainfall_cumulativeとrainfall_tip_countを送信する必要があります。rainfall_tip_count単独では既存の雨量保存経路に入りません。DBスキーマと送信仕様は変更していません。

排液グラフは直近72時間を固定表示し、メインP41と同じカード・グラフ枠・文字サイズを使用します。左軸は時間別の棒、右軸は日ごとに分けた積算線です。日本時間0時に薄い縦線を描きます。

排液3地点のクロスヘアと値ラベル・下部時刻はメインP41と同じ共通処理を使用し、排液タブ内の3地点だけで同期します。

排液タブ上部の縦軸設定で、時間別（左軸）と日積算（右軸）の最小・最大をL単位で3地点へ一括反映できます。空欄は自動調節です。適用済み範囲はブラウザに保存し、更新・再読込・ズームリセット後も維持します。「縦軸を自動に戻す」で解除できます。

U-TechメインのP01・P11は温湿度を1枚に統合し、Plusメンテと同じcreateTempHumChart・setTempHumYAxis・applyTempHumYAxisを共通JSから使用します。湿度は左軸、温度は右軸です。メインのP01→P11の軸連動は温度と湿度で個別に設定でき、表示設定は統合カードのtempChartP01・tempChartP11を引き継ぎます。独立した湿度カードとその表示選択肢は削除しました。
