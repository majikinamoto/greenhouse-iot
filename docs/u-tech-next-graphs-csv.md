# U-Tech Next グラフとCSV

Next専用画面に「予報」「データ出力」タブを追加する。本体の画面、DB、取得CLI、cronは変更しない。

## グラフ

- 本体と同じChart.js 3.9.1、Hammer 2.0.8、zoom plugin 1.2.1を使用する。
- 基本の枠は幅400px、描画領域の高さ280px。小さい画面では幅に合わせる。
- 6グラフのクロスヘアとツールチップを時間単位で連動する。タッチにも対応する。
- 欠損時刻の線をつながず、連動表示は同じ時刻の「欠損」を表示する。
- PCのドラッグによる時間軸拡大を全グラフへ反映する。リセットで全グラフを00〜23時に戻す。
- CDNを利用できない場合はグラフの案内を表示し、表・概要・CSVは利用可能にする。

## CSV

- 画面で読み込み済みの1日の保存データを使用する。追加のDBアクセスは行わない。
- 19項目をグループ別チェックボックスで選択できる。全選択・全解除がある。
- 全25時刻を保存順に出力し、翌日00時はis_boundary=1とする。
- 予報日、対象日時JST、取得日時JST、地点ID・名前・座標、モデル、タイムゾーンを必ず含める。
- 気象列のヘッダーに単位、隣のsource列にJMA由来/Open-Meteo算出と直前1時間値の区別を含める。
- UTF-8 BOM、CRLF、全セルの引用符と引用符のエスケープを使用する。欠損は空欄、0は0。
- 集計値・実測値・独自推定値は含めない。地点対応未設定のuser_id/point_idも含めない。
- 日付入力を変更しただけでは出力データは変わらない。表示ボタンで再取得中、未保存、取得失敗の場合はダウンロードを無効にする。

## 検証

scripts/test-next-ui.cjsで合成予報を使い、PC/スマートフォン、マウスによるクロスヘア・ツールチップ・拡大の連動、リセット、実際のCSVダウンロード、選択列、25時刻、BOM、欠損、境界値、失敗時の無効化、既存U-TechのlocalStorage不変を確認する。実DBと気象APIは呼び出さない。
