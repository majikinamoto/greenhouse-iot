# 蒸散量の実測値補正

## 今回の実装（DB変更なし）

蒸散量タブに「推定値」「実測値補正」の子タブを設置する。葉面積・Kc・ノズル吐出量・日射透過率・ハウス内風速・かん水回数は既存の入力を共用する。補正実測先のuser_idは実測値タブの閲覧IDから独立し、P01の温度・湿度を既存の実測APIから取得する。風速・CO2の実測値は補正に使用しない。

比較日数は1～10日、初回は5日。補正用user_idと日数は試算設定であり、共有保存はまだ行わない。補正用user_idは前回値と最大10件の履歴をブラウザーのlocalStorageに保存し、実測値タブの履歴とは独立させる。日数は初回5日に戻る。

本日（Asia/Tokyo）を比較最終日とし、選択日数に本日を含める。10月9日・5日の場合は10月5～9日。本日の実測値がまだない20時台は10月5～8日の4日分で平均し、10月4日を追加しない。1日を選択し本日が未測定の場合は補正なし。各比較日の前日18:10に採用済みの予報を既存の`water.php`から取得する。実測先の地点も、現在Nextで採用している予報地点と比較する。

各日・時間帯ごとにP01の有効な測定値を平均し、保存予報との差を求める。13時台は13:00:00～13:59:59。測定1件でも使用する。複数日は各日の差を同じ重みで平均し、使用日数と比較に使用した測定件数を記録する。温度・湿度は独立に計算し、比較できない時間帯・項目は補正差をnullとし、元の予報値を使う。取得エラーはデータ不足と混同せず表示して試算を停止する。

温度差は℃、湿度差は％ポイントとして対象日の予報に加算する。湿度は0～100％に制限し、範囲調整を表示・CSV記録する。補正後の温湿度から飽差g/m³・VPD kPaを計算する。飽差への独立した補正はしない。日射と風速の計算方法は既存式を引き継ぐ（日射は既存の透過率、風速は入力値）。

時間帯別の差グラフは温度・湿度の2つ。選択日の補正差を太線、比較各日の差を薄線で表示し、ゼロ基準線・連動クロスヘア・ドラッグ拡大・表示リセット・下部の比較数値を備える。比較表には補正後の温湿度・飽差も載せる。

補正蒸散量は選択日とその前2日の3日分を、本日を基準に求めた時間帯別補正差で試算して表示する。今回は全3日とも現在の設定による試算。6本のグラフは既存レンダラーを共用し、棒・日累積線・日替わり線・連動ポインタ・必要水量／総時間／1回時間の表示をそろえる。

試算CSVは子タブまたはデータ出力タブから、最後に計算した3日分を出力する。試算種別、予報対象日・取得日時、補正実測先、比較日数・期間、差、使用日数・測定件数、補正後の温湿度・飽差、範囲調整、6本の計算結果、元の植物・共通設定を含む。欠測は空欄と状態列で区別する。

## DB対応で残る作業

- 推定対象ハウスと補正実測先の対応、補正日数を共有設定として保存。既存の設定保存とは別の保存操作を維持する。
- 日数・実測先の変更だけでは共有設定を更新しない。「設定を保存」した設定を次回18:10採用時に使う。
- 採用時の予報・補正設定・比較差・有効件数・補正後計算結果を履歴として固定する。
- 保存履歴を優先した過去日の表示と、試算CSVから独立した保存履歴CSVを実装する。
- DB対応が済むまで補正の設定保存・履歴CSVボタンは無効にし、理由を表示する。
- 日射センサー導入後の補正は今回の対象外。
