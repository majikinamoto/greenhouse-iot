# 蒸散量・かん水量

## 導入

更新コードの配備前に、既存のgreenhouse DBへ `u-tech-next-water-schema.sql` の追加2テーブルを作成する。既存テーブルを変更しない。SQLは本作業では実行していない。
初期値はすべて空欄。蒸散量タブで6本共通の透過率・ハウス内風速・かん水回数と、各樹の葉面積・Kc・吐出量を入力して保存する。全端末で共有し、版番号による同時更新検出を行う。
毎日18:10 JSTの既存cronを継続使用する。初回＋5分間隔5回（最大6回）取得。最初にDBへ接続できた時点の設定を取り込み、再試行中も固定する。DB障害で18:10の設定を読めない場合は接続回復時点になる。
予報25行と蒸散量スナップショットを同じトランザクションで保存し、保存済みの日は変更しない。導入前の予報には当時の設定がないため、蒸散量履歴を遡って作成せず未計算とする。

## 計算

資料 `!灌水試験_灌水量計算用_R8.xlsx` の「ペンマン式」を使用。FAOペンマン・モンティース式への置換はしていない。

```
Es = 6.1078 exp(17.2694 T / (T+237.3)) [hPa]
Ea = Es RH/100
Δ = 0.4495 + 0.2721e-3 T + 0.9873e-3 T² + 0.2907e-5 T³ + 0.2538e-6 T⁴
λ = 2.5 - 0.0024 T
f(u) = 0.26 (1+0.54 u)
Rs_hour = outdoor_shortwave_W_m2 × 0.0036 × transmission_percent/100
ET_hour = max(0, Δ/(Δ+0.66) Rs_hour/λ + 0.66/(Δ+0.66) f(u)(Es-Ea)/24)
litres_hour = ET_hour × Kc × leaf_area_m2
daily_minutes = daily_litres / nozzle_l_min
cycle_seconds = round(daily_minutes / cycles_per_day × 60)
```

風速は入力したハウス内値を直接使用。屋外用46cmの高さ換算はユーザーの指示により省略。元資料の10/7サンプルは高さ換算付きで3.5177546104 mm/day、換算省略で3.5400009870 mm/day。同じ条件が24時間続く場合の時間積算と日式は一致する。時間変動がある場合、日平均で計算した値とは一致しないことがある。実測Kcはユーザー提供の葉面積用係数として扱う。

時刻h〜h+1の計算はhの気温・湿度とh+1の直前1時間日射を組み合わせる。瞬時値を時間内代表値とする近似。最後の区間には翌日00:00の境界日射を使用する。夜間も計算。欠測はnull、負値は0。日積算は0時にリセットし、欠測以降は部分積算と明記して日水量・時間は未確定にする。

## 表示・出力

通常表示は最新の保存済み予報対象日までの3日間（翌日を上限）。前の2日は固定履歴、最後の日だけ入力中の値で再計算。振り返りは指定日±1日の固定履歴。各日には前日の予報取得処理で保存した値を使う。棒は各1時間、線は毎日0からの累積。6本の時刻・クロスヘア・ツールチップが連動し、軸範囲を共通化。
データ出力では既存期間入力を使って保存値CSVを出力。振り返りでは表示中の3日分を出力。日時、取得日時、式の版、6本の時間値・積算・日量・時間・全設定・状態を含む。欠測・未計算の数値は空欄。設定入力中の試算を固定履歴CSVへ混ぜない。
